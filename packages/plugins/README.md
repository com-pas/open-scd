# `OpenSCD Official Plug-ins`

All the official plug-ins are listed [here](https://github.com/com-pas/open-scd/blob/main/docs/plug-ins.md).

This package is published to npm as `@compas-oscd/plugins` and is maintained in the `com-pas/open-scd` repository. It is part of the OpenSCD codebase consumed by `compas-open-scd` as an npm dependency rather than via a shared fork.
